# Design context — 灯序

## Product
Non-commercial online multiplayer time-deduction game (Paris-1920-like rules, original content). Brand: **灯序**. Setting: 港湾剧院 · 1924.

## Aesthetic
Quiet archival theater: footlights of warm amber on deep teal-ink curtains. Long sessions staring at notes. Not a SaaS dashboard.

## Typography
- Display: Fraunces
- UI / body: IBM Plex Sans
- Notes / codes: IBM Plex Mono
Never Inter / Roboto / Arial / system-ui defaults.

## Color
CSS variables in globals.css: `--curtain`, `--stage`, `--ink`, `--amber`, `--green-win`, `--parchment`. Avoid purple gradients, warm-cream+terracotta, broadsheet hairlines.

## Structure
One job per screen. Lobby = brand + enter room. Desk = map + current action. No card collage hero. Green shared clues most prominent; white private only in personal zone.

## Motion
1. Green-window reveal
2. White-window personal reveal
3. Turn / submit-window pulse
No decorative floaters.
